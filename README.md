Portfolio — Modern Dark Mode

This is a minimal, responsive developer portfolio scaffold with a deep-navy dark aesthetic.

Colors:
- Background: #0F172A
- Cards: #1E293B
- Accent: #38BDF8

Files:
- index.html — main page
- styles.css — styles and layout
- script.js — small UI polish (smooth scroll + year)

How to view locally

Open `index.html` in your browser, or serve with a simple HTTP server:

PowerShell

```powershell
cd c:/laragon/www/portfolio
python -m http.server 8000
# then open http://localhost:8000
```
